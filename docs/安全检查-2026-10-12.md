# 项目安全检查（2026-10-12）

本次为关键代码检查及本地回归验证，不等同于完整渗透测试或依赖漏洞扫描。

## 已修复

| 问题 | 影响 | 修复 |
|---|---|---|
| 诊断上下文直接按 field_id 读取地块 | 已登录用户可能读取其他用户地块的作物、生长阶段等信息；后续生成记录可能关联到其他用户地块 | 普通与 SSE 接口在执行前校验归属；底层工具查询同时过滤所有者及软删除状态 |
| bcrypt 密码截断 | UTF-8 超过 72 字节的不同密码可能被视为同一个密码 | 注册校验字节长度；哈希与验证函数拒绝超长输入 |
| 上传完整读取后才判断大小 | 超大文件造成额外内存消耗 | 单次最多读取上限加一字节；此措施不替代网关和 multipart 请求体大小限制 |
| 图片像素限制只依赖 Pillow 默认警告 | 超过设置阈值的图片仍可能开始解压 | 解码前显式检查像素数量 |
| 异常原文通过 errors、trace、tool_calls、SSE 和 health 返回 | 可能暴露 SQL、路径、第三方服务信息 | 返回通用错误，内部异常保留在服务端日志 |
| 生产模式允许开发 JWT 密钥及不安全 CORS | 使用公开默认密钥可伪造令牌 | production/prod 模式拒绝默认或短密钥、DEBUG=true、null/* 来源 |
| JWT 不要求过期字段，sub 转换可能报 500 | 令牌校验边界不完整 | 强制 sub/iat/exp；无法解析用户 ID 时返回 401 |
| 登录未排除软删除用户 | 已删除账号仍可获得登录令牌 | 登录查询排除软删除账号 |

注意：此前使用超过 72 字节密码注册的账号，需重置为符合限制的新密码。本次未修改数据库和实际密钥。

## 上线前仍需处理

- 登录、注册和模型调用未见限流措施；应在部署网关设置速率、请求体大小与并发限制，并按用户控制模型调用额度。
- 图片通过公开 /media 或对象存储 URL 访问，知道 URL 即可读取；涉及隐私时需要用户鉴权或短期签名链接。随机文件名不等同于访问控制。
- SSE 生成器缺少断连后的任务取消与等待清理，客户端退出后可能继续消耗模型调用资源。
- 默认演示账号及基础设施开发凭证必须在上线前移除或更换；配置检查仅在 ENV=production/prod 时生效。
- 依赖采用最低版本约束，本次未做联网漏洞库审计，不能据此认定依赖无已知漏洞。

## 项目亮点

- 诊断 FSM 与咨询工具循环按任务性质分工，节点工具白名单控制调用范围。
- 置信度拆解为 margin/agreement/coverage，结合农药规则形成两道输出闸门。
- RAG、引用、执行轨迹和反馈记录让建议可以追溯。
- 外部依赖具有降级路径，界面能反映降级状态。
- 地块档案、诊断、用药记录与农事任务形成业务闭环。

README 的模型验证准确率与检索命中率属于已有项目报告，本次未重跑这些评测；不能直接作为真实田间诊断准确率。
